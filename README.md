# SolidWorks Automotive Differential Gearbox CAD Model

A **3D CAD modelling and assembly project developed using SOLIDWORKS**, focused on the design and assembly of an automotive differential gearbox.The project consists of multiple individually modelled mechanical components that are integrated into a complete **differential gearbox assembly**.

---

## Project Overview

The objective of this project was to develop a detailed 3D CAD model of an automotive differential gearbox by designing individual mechanical components and assembling them into a complete mechanical system.

The project demonstrates practical application of:

- 3D mechanical CAD modelling
- Parametric part design
- Mechanical component modelling
- Assembly design
- Component integration
- Automotive drivetrain modelling
- SolidWorks-based design workflow

---

## Software Used

- SolidWorks(3D CAD modelling)


---

## CAD Model
The project includes **7 individually modelled SolidWorks components**, developed as separate `.SLDPRT` part files.

These components are integrated into the main **`Differential Gearbox.SLDASM` assembly file**, which represents the complete assembled CAD model.


## Modelling Workflow

The differential gearbox CAD model was developed through the following
workflow:

Individual Component Design
            ↓
      3D Part Modelling
            ↓
    Parametric CAD Features
            ↓
   Component Geometry Development
            ↓
      Assembly Integration
            ↓
   SolidWorks Assembly Design
            ↓
 Differential Gearbox CAD Model
