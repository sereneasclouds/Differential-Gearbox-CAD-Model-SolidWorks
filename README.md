# SolidWorks Automotive Differential Gearbox CAD Model

A **3D CAD modelling and assembly project developed using SOLIDWORKS**, focused on the design and assembly of an automotive differential gearbox.

The project consists of multiple individually modelled mechanical components that are integrated into a complete **differential gearbox assembly**.

---

## Project Overview

The objective of this project was to develop a detailed 3D CAD model of an automotive differential gearbox by designing individual mechanical components and assembling them into a complete mechanical system.

The project demonstrates practical application of:

- 3D mechanical CAD modelling
- Parametric part design
- Mechanical component modelling
- Assembly design
- Component integration
- Automotive drivetrain modelling
- SolidWorks-based design workflow

---

## Software Used

- **SOLIDWORKS**
- SolidWorks Part Design
- SolidWorks Assembly Design
- 3D CAD Modelling
